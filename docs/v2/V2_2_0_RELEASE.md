## Compatibility and rollback

Existing schema-1 engineering files and inline asset integrity remain unchanged.
Optional `org.stray.atlas` metadata is informational and retains stable template
ID/catalog revision; user projects remain independent of later catalog edits.
Preview/selection never replaces the editor, cancel preserves dirty work, and
opening a confirmed new template does not replace the independent signal project.
No autosave/cloud or persisted history. Narrow layouts are emulated Chrome,
not physical-phone, screen-reader or all-browser certification.

For rollback, review the full **`v2.1.0..v2.2.0`** range and revert in reverse order
with new commits, run appropriate checks, deploy through existing Pages and
verify the restored behavior. Reverting only docs/version leaves Atlas code.
Preserve user file backups and history; never reset/force-push/move public tags.
Stop after V2.2.0. Next catalog expansion requires its own approved scope; no DC,
nonlinear, transmission-line or other solver implementation is part of this release.
