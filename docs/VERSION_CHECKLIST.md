# 逐版本开发清单

更新：2026-10-23。V2.3.0 正在验收，详见[直流发布记录](v2/V2_3_0_RELEASE.md)。当前公开应用 **V2.2.0 典型电路图谱**，完整公网验收已通过；
最终提交、标签及8/8交接见 [V2.2.0 Release](https://github.com/STRAY-FLZ/circuit-equivalence-lab/releases/tag/v2.2.0)。
“规划”不代表已实现；元件能显示/编辑不代表可仿真，数据契约不代表已有完整工具。

| 版本／内部阶段 | 已实现 | 暂未实现／边界 | 状态 |
| --- | --- | --- | --- |
| V1 · M0–M8 | 电阻网络、显式拓扑、等效电阻、串并联/Δ↔Y、独立数值验证、SVG 对比、五阶段课程/MathML、主题、响应式和部署 | 任意电源驱动的通用求解、通用编辑器当时未提供；历史 package 为0.1.0，不补造标签 | 已发布，保留于 V2 |
| V2.0-A | 广义工程模型、连接/几何分离、类型化引擎、测量/PCB接口、文件与编辑设计；D01–D09 业主审阅 | 设计本身不实现 PCB、硬件或通用仿真 | 内部设计已验证 |
| V2.0-B | 稳定 UUID、锁定元件定义、多引脚与显式连接、工程校验、schema1 JSON、内联资产完整性、V1 适配器 | 外部大数据容器、任意旧格式迁移、实际 EDA 格式集成 | 已集成发布 |
| V2.0-C | SVG 编辑、R/C/L/独立电源、引脚接线、结点/标签/接地/求解参考、参数、旋转/移动/删除、历史、文件往返 | 多选、复杂布线路径编辑、云端/自动保存、撤销历史持久化 | 已集成发布 |
| V2.0-D／V2.0.0 | 用户电阻电路的候选发现、前后预览、端口数值验证、事务写回/撤销及课程，与 V1 共存 | 混合器件变换、跨图纸导电网络变换；验证不确定不能提交为已验证编辑 | 已发布 |
| V2.0.1 | 引脚/结点拖拽接线、连续虚线预览、屏幕空间吸附、取消及历史/文件持久化 | 实体触控笔/全浏览器认证 | 已发布 |
| V2.0.2 | 拖动已有元件只移动原件；左栏每次激活仅放置一个；数量/身份与历史保留 | 未引入新求解器 | 已发布 |
| V2.1.0 | 五种采样信号、最多四通道示波器/光标/缩放、全记录测量、FFT/Hann、显式单位 CSV、来源/资产/结果持久化 | 硬件采集、任意电路波形、相位/THD/PSD认证、滤波、非均匀采样重采样；FFT需2的幂 | 已发布，504项基线测试 |
| V2.2.0 · 典型电路图谱 | 十二类/89电路族，26个真实模板；动画、键盘、编辑器接入、文件往返及信号保留已在公网验证，539项测试通过 | 69电路族暂无模板；不实现 DC/AC/暂态求解，不等于全书覆盖 | 应用已发布；最终身份与交接见Release |
| V2.3.0 · 直流电路分析 | 独立 MNA、R/V/I/四类受控源、实际矩阵与 V/I/P、残差/KCL/功率、编辑失效与定位、16 个图谱入口 | 单图纸与规模限制；不含 AC/暂态/非线性/独立网孔法；结果会话保存 | 实现完成，最终验收与发布进行中 |
| V2.4 · 滤波与频率响应 | 图谱可提供部分被动滤波拓扑；信号实验室已有采样 FFT | 电路频域求解、传递/相位响应、滤波处理、Bode、RLC频率分析 | 规划，未开始 |
| V2.5 · 竞赛工作区 | 工程模型中有记录接口 | 经来源核实的真题索引、要求/评分指标、方案、测试与报告工作流 | 规划，未开始 |
| V3.x · 进阶电路与模拟电子 | 现有基础可复用 | 暂态/交流、运放与受控源、非线性器件、放大/反馈、电源、进阶电路理论等，逐模块交付 | 规划，未开始 |
| V4.x · 数字、嵌入式与控制 | 尚无完整功能模块 | 逻辑/时序、MCU外设与通信、采集、传感器、PID/闭环控制等 | 规划，未开始 |
| V5.x · PCB工程 | 中立引脚到焊盘/器件映射数据契约 | 实际封装/布局/布线、2D/3D、ERC/DRC、BOM、EDA互操作与受验证工程导出 | 规划，未开始 |
| V6.x · 综合工程 | 尚无完整功能模块 | 跨领域综合工程项目及更高阶专业能力，依需求与基础能力扩展 | 规划，未开始 |
