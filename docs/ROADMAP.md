# M0～M6 开发路线

每轮只实施一个模块，先完成该轮测试与验收，再进入下一轮。以下是规划，不代表已有业务功能。

| 阶段 | 内容 | 验收条件 |
| --- | --- | --- |
| M0 项目基础架构 | React/TS/Vite、严格检查、模型与契约、基础页面、文档 | install/typecheck/lint/test/build 全部实际通过；有限正电阻与数据完整性测试有效；真实启动测试成功；支持深浅主题；无 M1～M6 算法 |
| M1 拓扑识别 | 从理想导线构建电气节点，建立连接点到节点的映射与连通分量 | 空网络、孤立点、导线链/环、重边、自环、不连通子网、多端子均有测试；每个点恰好归属一个节点；坐标变化不影响拓扑；结果确定性与 ID 策略有文档 |
| M2 电阻网络求解 | 节点电压法、两端等效电阻与求解状态 | 与可手算的小网络结果比较；同节点短路、不连通开路、无效端子、奇异或病态情形明确处理；容差与数值误差可解释；不依赖视图 |
| M3 串并联等效 | 识别局部适用结构、生成新网络、记录等效依据 | 已知串并联示例与不适用反例有测试；保留外部端子与边界连接；输入网络不变；变换前后由 M2 验证等效 |
| M4 Y–Δ 等效 | Y→Δ 与 Δ→Y 的适用条件、正阻值变换及教学步骤 | 非对称示例可验证；三端口边界保持；反向变换与极端尺度测试；拒绝不适用选区；由 M2 验证端口等效 |
| M5 惠斯通电桥与教学 | 平衡/不平衡电桥示例、公式和逐步推导 | 解释平衡条件及适用前提；数值与 M2 一致；不平衡桥不错误套用串并联；教学结论可追溯到计算与变换 |
| M6 SVG 交互电路图 | 独立布局、节点/元件/端子绘制、选取与交互 | 几何变化不修改电气连接；绘制与模型一致；支持桌面/移动布局、键盘可达与主题；交互不能破坏模型校验；完整学习流程可验收 |

M0 不提供节点电压法、串并联/Y–Δ 算法、SVG 绘图或拖拽编辑器。M6 的编辑范围在该轮再确认，不预先引入编辑框架。数据库、付费 API 与部署不属于当前路线的必要依赖。
